# Features

*Last reviewed: 2026-10*

One folder per shipped capability, created when the feature is implemented (not before). Each folder has an `overview.md`: what it does, why it exists, key invariants, which tests protect it. Add companion files as needed. Until a feature has a folder, its rules live in `docs/product/behaviour-rules.md`.

Suggested folders, in build order: `live`, `tray-and-alerts`, `history`, `sync-and-import`, `localization`.

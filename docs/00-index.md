# Documentation index

Agents start at `AGENTS.md` (shared) or `CLAUDE.md` (Claude Code). Area rules are in `.claude/rules/`, skills in `.claude/skills/`; how they fit together: `guides/maintaining-agent-instructions.md`.

| Folder | Purpose |
|---|---|
| `product/` | What the app is and how it behaves |
| `design/` | Tokens, components, screens, states, languages, accessibility |
| `engineering/` | Data, sync and import, WPF mapping, C# rules, testing, release |
| `decisions.md` | One log of decisions and their reasons |
| `guides/` | How to do common tasks (add a sensor, control, setting, translation; run the gallery) |
| `features/` | One folder per shipped feature (created as features are built) |
| `plans/` | Roadmap, backlog, spikes and their notes, questions and decisions of the build (`questions.md`), UI review brief, handoff (`handoff.md`) |

## Reading order for a new contributor

1. `product/vision-and-scope.md`
2. `product/behaviour-rules.md`
3. `design/screens-and-states.md`
4. `engineering/data-model.md`
5. `plans/roadmap.md`


## Architecture

`engineering/architecture.md` (five projects, rules, glossary) and `guides/adding-a-sensor.md` (how forks add a sensor).

# Run the control gallery

*Last reviewed: 2026-10*

1. `dotnet run --project src/Deskair.App -- --gallery` (Debug builds, on Windows).
2. The gallery lists every control and chart in all states, using the simulated sensor.
3. Switch theme (light, dark) and language (English, Ukrainian) and check each item.
4. Compare with `design/prototype/index.html`, and check keyboard focus and text fit.

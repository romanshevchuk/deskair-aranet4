# Contributing

- Branch names: `feature/<ID>-short-name`, `fix/<short-name>`, `docs/<short-name>`. IDs come from `docs/plans/backlog.md`.
- Commits: imperative, start with the ID when there is one, for example `LIVE-03: add hover readout to chart`.
- Every pull request: tests pass, no hard-coded strings or colours, English and Ukrainian strings added, docs updated, screenshot for UI changes (light and dark).
- Decisions that change scope, data format or platform need an entry in `docs/decisions.md`.

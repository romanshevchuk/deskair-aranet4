# Docs rules

- Update "Last reviewed" on every doc you change.
- Tables over prose for specs. Concrete, checkable wording ("fixed at 1,000 ppm", not "reasonable").
- Link to other docs; do not duplicate their content.
- Everything the agent needs must be in the repo, not behind an external link.
- Decisions go in `docs/decisions.md`; unanswered questions in `docs/plans/questions.md`.

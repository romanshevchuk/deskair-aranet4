# Deskair

A Windows desktop monitor for the Aranet4 CO₂ sensor. Live readings, a tray icon that changes colour with air quality, gentle alerts, and long-term history stored on your PC.

- **Live:** CO₂, temperature, humidity and pressure, with hover charts and a 24 h ribbon.
- **Tray:** a coloured icon and a quick flyout (left-click) or menu (right-click).
- **History:** day, week, month and year views, night-only averages, and clear gaps when data is missing.
- **Private:** all data stays in `Documents\Deskair` on your PC.
- **Languages:** English and Ukrainian.

Requires Windows 10 (version 2004 or later) or Windows 11, and Bluetooth LE.
